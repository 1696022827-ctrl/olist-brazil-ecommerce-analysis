# PowerBI 看板搭建指南

> 从零到一，按步骤操作，15 分钟搞定。
> 所有 DAX 度量值代码在同目录下的 `powerbi_dax.txt` 里，直接复制粘贴。

---

## 第一步：导入数据

1. 打开 **PowerBI Desktop**（免费版就行，微软官网下载）
2. 左侧菜单栏点 **获取数据 → 文本/CSV**
3. 依次选择 `output/csv/` 下的 4 个文件：
   | 文件 | 用途 |
   |------|------|
   | `clean_wide.csv` | **核心明细表**（订单级，最全字段） |
   | `rfm_result.csv` | RFM 用户分层表 |
   | `category_sales_stats.csv` | 品类销售汇总（辅助） |
   | `category_review_stats.csv` | 品类评价汇总（辅助） |
4. 加载时 PowerBI 可能提示"是否应用更改"，点 **应用更改**

---

## 第二步：建立表关系

点左侧 **模型** 图标（就是一个黄色小方块那个），拖拽建立关系：

```
clean_wide[customer_unique_id]   ←→   rfm_result[customer_unique_id]
```

- 关系基数：**多对一**（一个用户多个订单，一个用户一个 RFM 记录）
- 交叉筛选：**双向**（这样切 RFM 分层时能联动 clean_wide 里的订单）

> category_sales_stats 和 category_review_stats 是独立的汇总表，不需要和 clean_wide 关联，直接在品类图里用就行。

---

## 第三步：创建度量值

1. 点顶部菜单 **建模 → 新建度量值**
2. 把 `powerbi_dax.txt` 里的代码逐条复制进去，每条代码对应一个度量值
3. 建议按顺序创建：KPI 类 → 趋势类 → 分层类 → 评价类

---

## 第四步：搭建看板（建议 2-3 页）

### 📊 看板 1：销售总览

| 位置 | 图表类型 | 字段 / 度量值 | 说明 |
|------|---------|--------------|------|
| 顶部左 | **卡片图 × 4** | 总订单数、总GMV、客单价、总用户数 | 核心 KPI |
| 顶部中 | **卡片图 × 2** | 平均配送天数、延迟率 | 物流指标 |
| 左侧大 | **面积图 / 折线图** | X 轴 = 下单月份，Y 轴 = GMV 和 订单数 | 月度趋势，黑五峰值要标出来 |
| 右侧大 | **条形图** | 轴 = category_cn，值 = 销售总额（用 category_sales_stats 表） | TOP10 热销类目 |
| 底部 | **切片器 × 2** | 下单月份、customer_state（州） | 全局联动筛选 |

### 👥 看板 2：用户分层 + 评价分析

| 位置 | 图表类型 | 字段 / 度量值 | 说明 |
|------|---------|--------------|------|
| 顶部左 | **环形图 / 饼图** | RFM 分层 | 用户分层占比（6层） |
| 顶部右 | **柱状图** | X 轴 = 配送时间段，Y 轴 = 平均评分（用 clean_wide） | 配送慢 → 差评关系 |
| 左侧大 | **表格 / 矩阵** | category_cn、有评价订单数、平均评分、差评率 | 品类差评排行（用 category_review_stats 表） |
| 右侧大 | **柱状图** | 轴 = 评分分段，值 = 订单数 | 1-5 分评分分布 |

---

## 第五步：美化（加分项）

- **主题**：顶部菜单 **视图 → 主题** 选一个好看的深色主题（比如 "Executive"）
- **中文标题**：所有图表的标题改成中文（"销售额"、"订单量"、"用户分层"）
- **数据标签**：条形图/柱状图右键 → **显示数据标签**，让数值直接显示在图上
- **联动**：点任意条形图的柱子，其他图表自动过滤，面试展示时非常酷
- **悬浮提示**：图表 hover 时会自动显示详情，可以截进 PPT

---

## 快速排错

| 问题 | 解决方案 |
|------|---------|
| GMV 数值巨大 / 重复计算 | clean_wide 是 **商品级**（一个订单多个商品就多行），涉及订单数必须用 `DISTINCTCOUNT(order_id)`，不要直接 `COUNT` |
| RFM 分层切片器不联动订单 | 检查第二步的表关系是否设为"双向" |
| 类目切片器里出现一堆空值 | clean_wide 里有商品没匹配到 category_cn，powerbi_dax.txt 里加个过滤 `category_cn <> "其他类目"` 或者直接用 category_sales_stats 表 |
| 日期不能做时间智能 | 在 clean_wide 里选 order_purchase_timestamp 列 → 右键 → **标记为日期** → **标记为日期表** |
