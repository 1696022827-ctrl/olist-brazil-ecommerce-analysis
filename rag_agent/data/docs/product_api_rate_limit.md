# OpenAPI 调用限流规则

为保障服务稳定，云效科技 OpenAPI 对各版本实行差异化限流：

| 版本   | 每日调用上限 | QPS 上限 | 价格     |
|--------|--------------|----------|----------|
| 免费版 | 100 次/天    | 5        | 0 元     |
| 专业版 | 10,000 次/天 | 50       | 299 元/月|
| 企业版 | 不限量       | 500      | 按需报价 |

超出限流后接口返回 HTTP 429，需等待至次日 0 点（免费版）或下一个计费周期重置。
企业版可通过工单申请临时提升 QPS 上限。
所有接口均要求在请求头携带 Bearer Token 鉴权。
